# Triage 标签

各工程技能使用五种规范化 triage 角色。本文件将这些角色映射到本项目议题跟踪器中的实际标签。

| Matt Pocock 技能中的标签 | 本项目使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给后台代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如“应用后台代理就绪标签”）时，使用表格中对应的本项目标签。
